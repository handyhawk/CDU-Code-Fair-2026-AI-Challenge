# CDU-Code-Fair-2026-AI-Challenge

To setup both frontend and backend, follow these following steps:

1. Backend setup
- Open terminal using Ctrl + J
- Change directory to backend by typing in the terminal "cd backend"
- Install required packages for backend by typing "pip install flask pandas scikit-learn"
- Type in "python app.py". You should see "Running on http://127.0.0.1:5000"
- That's wrap up the backend setup, now we are going to setup the frontend

2. Frontend setup
- Create another terminal using the "+" icon in the terminal
- Change the directory to frontend by typing "cd frontend"
- Install required packages for frontend by typing "pip install streamlit requests"
- Type in "streamlit run app.py". The Streamlit app would automatically pop up on your browser.
If not, copy the Local URL and paste it into your browser.
